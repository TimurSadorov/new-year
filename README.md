# Твой сладкий декабрь

Новогодний адвент-календарь на декабрь 2026 года. Дни открываются по местному времени устройства, а галочки просмотра хранятся в браузере.

## Локальный просмотр

Запусти из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

- Обычный календарь: `http://127.0.0.1:8765/`
- Демо со всеми доступными днями: `http://127.0.0.1:8765/?preview=1`

В обычном режиме подарки берутся из `gifts.json`. Демо всегда показывает заглушки и хранит галочки отдельно. В поле `image` укажи относительный путь к фото, оставив `null`, если нужна заглушка.

Зимний вальс повторяется по кругу. Если браузер блокирует автозапуск, музыка начнётся после первого нажатия. Кнопка сверху выключает музыку, а браузер запоминает выбор.

## Публикация

В GitHub открой **Settings → Pages → Deploy from a branch**, выбери ветку `main` и папку `/(root)`. Сборка не нужна.
