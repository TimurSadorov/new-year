# Твой сладкий декабрь

Новогодний адвент-календарь на декабрь 2026 года. Чтобы открыть день, его дата должна наступить, а все предыдущие подарки должны быть просмотрены. Браузер запоминает просмотренные подарки, и их лампочки продолжают гореть.

## Локальный просмотр

Запусти из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

- Обычный календарь: `http://127.0.0.1:8765/`
- Демо, где можно пройти все дни по порядку без ожидания дат: `http://127.0.0.1:8765/?preview=1`

Оформление меняется по местному времени. Рассвет начинается в 06:00, день в 11:00, вечер в 17:00. Для проверки добавь к ссылке демо `&time=dawn`, `&time=day` или `&time=night`.

В обычном режиме подарки берутся из `gifts.json`. Демо всегда показывает заглушки и хранит галочки отдельно. В поле `image` укажи относительный путь к фото, оставив `null`, если нужна заглушка.

Утром играет «Первый снег» с мягким фортепиано и челестой, днём — свинг «Новогодние огни» с бубенцами, контрабасом и трубой, вечером — спокойный «Тёплый свет» с акустической гитарой и вибрафоном. Каждая мелодия повторяется по кругу. Если браузер блокирует автозапуск, музыка начнётся после первого нажатия. Кнопка сверху выключает музыку, а браузер запоминает выбор.

Для салюта использованы фрагменты полевых записей [Fireworks - Pop Pop Crackle](https://freesound.org/people/el_boss/sounds/588198/) от el_boss и [Single Firework Shot - 01](https://freesound.org/people/P4INKILLA/sounds/841958/) от P4INKILLA. Обе записи доступны под CC0.

## Публикация

В GitHub открой **Settings → Pages → Deploy from a branch**, выбери ветку `main` и папку `/(root)`. Сборка не нужна.
